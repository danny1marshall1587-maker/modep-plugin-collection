# Cyber Blues Driver (LV2 Plugin for MOD Desktop & MODEP)

Authentic classic blues overdrive LV2 pedal for MOD Desktop & MODEP with touch-sensitive multi-stage gain clipping and fat boost.

## Installation
Drop the `cyber-blues-driver.lv2` bundle into your LV2 directory:
- **Windows**: `C:\Program Files\MOD Desktop\plugins\`
- **Linux / MODEP**: `~/.lv2/` or `/var/modep/lv2/`
- **macOS**: `~/Library/Audio/Plug-Ins/LV2/`
