# Cyber CV Reverser LV2

A specialized Control Voltage (CV) reverser and inverter utility plugin for MOD Desktop and MODEP (Raspberry Pi).

## Features

* Inverts incoming Control Voltage signals ({out} = 1.0 - V_{in}$).
* Smooth offset and curve shaping.
* Engineered to invert expression pedals, macro knobs, and LFOs without causing UI lag or page reloading errors.
* Built-in MOD GUI with responsive CV connection jacks.
