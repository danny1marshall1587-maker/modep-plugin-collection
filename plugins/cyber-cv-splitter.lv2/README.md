# Cyber CV Splitter LV2

A dual buffered Control Voltage (CV) splitter and distributor utility plugin for MOD Desktop and MODEP (Raspberry Pi).

## Features

* Splits 1 CV input into 2 isolated, buffered CV outputs with independent scale and polarity control.
* Allows a single expression pedal or CV macro to simultaneously control multiple parameters across different plugins.
* Zero latency, high precision 64-bit internal floating-point calculation.
