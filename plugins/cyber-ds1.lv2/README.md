# Cyber DS-1 Distortion (LV2 Plugin for MOD Desktop & MODEP)

Classic orange hard-clipping distortion LV2 pedal with big-muff style tilt tone stack.

## Installation
Drop the `cyber-ds1.lv2` bundle into your LV2 directory:
- **Windows**: `C:\Program Files\MOD Desktop\plugins\`
- **Linux / MODEP**: `~/.lv2/` or `/var/modep/lv2/`
- **macOS**: `~/Library/Audio/Plug-Ins/LV2/`
