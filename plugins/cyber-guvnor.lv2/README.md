# Cyber Guv'nor (LV2 Plugin for MOD Desktop & MODEP)

Vintage British high-gain stack amplifier overdrive / distortion LV2 pedal with 3-band EQ and LED hard-clipping.

## Installation
Drop the `cyber-guvnor.lv2` bundle into your LV2 directory:
- **Windows**: `C:\Program Files\MOD Desktop\plugins\`
- **Linux / MODEP**: `~/.lv2/` or `/var/modep/lv2/`
- **macOS**: `~/Library/Audio/Plug-Ins/LV2/`
