# Cyber Klon Centaur (LV2 Plugin for MOD Desktop & MODEP)

Legendary transparent overdrive LV2 pedal with dual-ganged clean blend and germanium diode soft-clipping.

## Installation
Drop the `cyber-klon.lv2` bundle into your LV2 directory:
- **Windows**: `C:\Program Files\MOD Desktop\plugins\`
- **Linux / MODEP**: `~/.lv2/` or `/var/modep/lv2/`
- **macOS**: `~/Library/Audio/Plug-Ins/LV2/`
