# Cyber Noble Drive (LV2 Plugin for MOD Desktop & MODEP)

Boutique Gallop / Noble tube-voiced overdrive LV2 pedal with asymmetric preamp stages, contour shaping, and bite.

## Installation
Drop the `cyber-noble-drive.lv2` bundle into your LV2 directory:
- **Windows**: `C:\Program Files\MOD Desktop\plugins\`
- **Linux / MODEP**: `~/.lv2/` or `/var/modep/lv2/`
- **macOS**: `~/Library/Audio/Plug-Ins/LV2/`
