# Cyber Screamer (LV2 Plugin for MOD Desktop & MODEP)

Classic green overdrive LV2 pedal with mid-hump drive, active tone control, and warm diode soft-clipping.

## Installation
Drop the `cyber-screamer.lv2` bundle into your LV2 directory:
- **Windows**: `C:\Program Files\MOD Desktop\plugins\`
- **Linux / MODEP**: `~/.lv2/` or `/var/modep/lv2/`
- **macOS**: `~/Library/Audio/Plug-Ins/LV2/`
