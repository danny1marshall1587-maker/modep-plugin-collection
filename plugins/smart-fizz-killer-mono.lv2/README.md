# Smart Fizz Killer (Mono) LV2

Mono edition of **Smart Fizz Killer**, saving **50% CPU** for mono pedalboards, live guitar rigs, and Raspberry Pi MODEP setups.

## Features
* 4-Stage Analog-Style Digital Smoothing:
  1. Cascaded Allpass Phase Smearing (softens harsh pick transients).
  2. Dynamic High-Frequency Fizz Clamp (envelope-followed surgical cut).
  3. Tanh Soft-Clipper (analog saturation).
  4. Tilt EQ & Body resonance.
* 1 Audio Input, 1 Audio Output.
* 50% CPU savings compared to the stereo version.
